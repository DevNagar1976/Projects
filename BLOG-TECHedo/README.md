# Growly — React + Vite JavaScript

This is the standalone JavaScript/JSX version of the Growly marketing landing page. It contains no TypeScript source files.

## Run the project

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Main files:

- `src/App.jsx`
- `src/main.jsx`
- `src/styles.css`

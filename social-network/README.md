# Instagram-style Frontend – Hanjari Prajapati

Frontend-only React + Vite project inspired by Instagram's familiar layout.

## Included
- Profile: Hanjari Prajapati / @hp___.18
- Link to the provided Instagram profile
- Instagram-style desktop + mobile layout
- Stories UI
- Feed posts
- Like interaction
- Suggested developer friends based on MERN / React / Node.js interests
- Follow / Following interaction
- Search suggestions
- Profile page and post grid
- Edit profile modal
- localStorage persistence (no backend, no MongoDB)

> Suggested accounts are fictional demo profiles and are not claimed to be real Instagram accounts.

## Run
```bash
npm install
npm run dev
```

Open the URL shown by Vite, normally http://localhost:5173
